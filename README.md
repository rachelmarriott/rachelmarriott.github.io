# rachelmarriott.github.io

Personal academic website, built with [Quarto](https://quarto.org) and served by GitHub Pages from `docs/`.

- Edit the `.qmd` pages and `styles.css`, then run `quarto render` (or Build → Render Website in RStudio) and commit `docs/`.
- To update the CV: replace `cv.pdf` (and `Marriott_CV.tex`), then render.
